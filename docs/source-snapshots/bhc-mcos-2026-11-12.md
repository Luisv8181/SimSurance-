## What the streak does and does not prove

The streak proves the page has not moved. It does not prove the page is
current: like the BHC overview page, this directory carries no revision date,
last-updated stamp, or document version anywhere on it, so "current" remains
unknowable and the check date is still the version. A directory that never
changes is also the page most likely to be stale without anyone noticing —
stability and currency are different claims, and only the first is established
here. The recheck therefore changes one thing only: the date on the check.
