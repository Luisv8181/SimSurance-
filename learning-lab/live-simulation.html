Educational Context

How Pyodide Executes Policy Simulation in WebAssembly

Pyodide brings the standard CPython runtime into the browser using WebAssembly. This means:

  • Identical Determinism: The pseudorandom number streams, dataclasses, and queue mechanics match the server-side Python unit test suite bit-for-bit.
  • Ledger Invariant Enforcement: If you craft a policy that double-counts capitation in downstream claims, simsurance.ledger.LedgerError will raise right in your browser!
  • No Server Required: Complete offline operation on GitHub Pages without tracking or data leakage.
